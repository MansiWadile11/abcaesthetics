(This block is a Handlebars comment, not an HTML one: Handlebars does not respect HTML comments, so an example partial call written inside is still executed, and a partial that shows how to call itself recurses until the build dies.) Three things to know before editing a page's values. 1. TITLE IS THE WHOLE TITLE. There is no brand suffix added here. A suffix looks tidy but costs ~28 characters on every page, and Google only shows roughly 60 - so on the pages that need the room most, the words that would have earned the click are the ones cut off. Each title carries the brand or the location only where it fits. 2. WRITE "&", NOT "&". Handlebars escapes these values on output, so an ampersand typed as & here is escaped a second time and the tab reads "Results & Before / After". Type the character you mean. 3. LENGTH. Aim for 60 characters or fewer for a title and 150-160 for a description. Shorter is fine; past those points the rest is dropped from the search result, so anything load-bearing goes first. robots is optional and defaults to "index, follow". Pages that exist to be arrived at rather than found - the thank-you page, the 404 - pass "noindex, follow" so they stay out of search while still passing link equity onward. --}} {{title}}
