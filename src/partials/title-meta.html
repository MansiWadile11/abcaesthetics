{{!-- Per-page title, description, canonical and social cards. Every page passes its own title, description, path and image as partial parameters - see any page's first line for the shape. (This block is a Handlebars comment, not an HTML one: Handlebars does not respect HTML comments, so an example partial call written inside is still executed, and a partial that shows how to call itself recurses until the build dies.) Parameters title the WHOLE title. No brand suffix is added here - see 1. description one or two sentences about THIS page. path the page's own url, leading and trailing slash: "/about/". Used for the canonical and for og:url. image the page's lead image, site-root relative. Optional; the site default is used when a page has none of its own. ogType "article" for the blog posts, otherwise omitted. robots defaults to "index, follow". Three things to know before editing a page's values. 1. TITLE IS THE WHOLE TITLE. There is no brand suffix added here. A suffix looks tidy but costs ~28 characters on every page, and Google only shows roughly 60 - so on the pages that need the room most, the words that would have earned the click are the ones cut off. Each title carries the brand or the location only where it fits. 2. WRITE "&", NOT "&". Handlebars escapes these values on output, so an ampersand typed as & here is escaped a second time and the tab reads "Results & Before / After". Type the character you mean. 3. LENGTH. Aim for 60 characters or fewer for a title and 150-160 for a description. Shorter is fine; past those points the rest is dropped from the search result, so anything load-bearing goes first. The absolute host comes from VITE_SITE_URL at build time (vite.config.js) rather than being typed into every page, so moving off the temporary Vercel address to the real domain is one environment variable, not 27 find-and-replaces. There is deliberately no "keywords" tag. Google has ignored it since 2009, and the one that used to be here listed the same treatment terms on all 27 pages including the privacy policy. --}} {{title}}
